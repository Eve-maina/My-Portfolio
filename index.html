    Best cloud security practices

    The security officer's handbook. Ten habits that would have stopped every breach on this station.

    1. Least privilege for every identity. Grant only the actions and resources a role needs, and let IAM Access Analyzer trim the rest.
    2. MFA everywhere, root locked away. Every human signs in with a second factor. The root user gets a hardware key and is never used day to day.
    3. No long-lived access keys. Use IAM roles and IAM Identity Center so credentials are short-lived and rotate on their own.
    4. Secrets live in a vault. Store them in AWS Secrets Manager, read them at runtime and rotate them on a schedule.
    5. Block public access by default. Turn on S3 Block Public Access at the account level and open things up only on purpose.
    6. Encrypt at rest and in transit. Use AWS KMS for data at rest and TLS for everything on the wire.
    7. Log everything, centrally. An organization-wide CloudTrail trail into a locked down bucket, with CloudWatch alarms on what matters.
    8. Detect threats continuously. Enable GuardDuty and Security Hub so suspicious activity is flagged in minutes, not months.
    9. Infrastructure as code, reviewed. Every change goes through Terraform plans and code review, never through console clicks.
    10. Back up and practise recovery. Automate backups, keep copies in a separate account and test restores before you need them.
